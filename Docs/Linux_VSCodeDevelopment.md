# How to develop DROD on Linux with VS Code

1. Make sure you got DROD building by following [Linux_Compilation.md](./Linux_Compilation.md).
2. Open the project folder in VSCode.
3. Use `Run and Debug` panel and use any of the existing launch configurations.
   - They will use docker builds by default.
4. Edit `.vscode/launch.json` and `.vscode/build.json` if you want to add more configurations.
